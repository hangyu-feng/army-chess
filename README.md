# Army Chess

Army Chess (四国军棋) is a web application for playing the four-player, two-versus-two version of Chinese Army Chess online with friends.

The project is intended to be self-hosted on a personal cloud server and accessed through a personal domain. Players should be able to create or join an online game, play with teammates, and compete against another team.

Game rules and the technical architecture will be defined during the planning phase. This repository currently contains the project foundation only.
